# RefactorBuddy (Centra Engine v4.0)

RefactorBuddy is a purpose-built architectural assistant designed to provide authoritative critiques and high-performance refactors for software engineering snippets.

## Why this topic?
This topic was chosen to demonstrate **Frontend Thinking** in a highly technical and structured domain. Unlike generic chat wrappers, RefactorBuddy transforms unstructured AI responses into a specialized workspace for developers:
- **High Utility**: Every developer needs a second pair of eyes on architectural debt.
- **Structural Innovation**: Demonstrates the ability to parse complex "Critique," "Refactor," and "Principle" segments from raw text into themed UI components.
- **Persona Engineering**: Showcases a strict "Senior Architect" persona that stays on topic and avoids conversational filler.

## Key "Frontend Thinking" Features

### 1. The Welcome "Handshake"
The first thing a user sees isn't a blank screen, but the **Centra v4.0 Active** welcome state. This includes a proactive system greeting and interactive examples based on real-world "Complexity Traps" and "God Objects," reducing the barrier to interaction.

### 2. Archival Comparison (Diff View)
To provide immediate value, the "Refactor" section includes an automated **Archival Comparison**. It presents a side-by-side view of the "Legacy" code versus the "Engineered" result, allowing developers to visually assess the architectural improvements.

### 3. Neural Processing UX
Instead of generic loading dots, RefactorBuddy uses a **Neural Processing** indicator. This reinforced "computation" feel, combined with a cyber-architect aesthetic (glassmorphism, Framer Motion animations, and emerald design tokens), ensures the product feels elite and purpose-built.

### 4. Error & Empty State Resilience
- **Error States**: Handled with specific "Neural Sync Fail" alerts.
- **Empty States**: Interactive, one-click code injectors that guide the user on how to use the engine.

## Tech Stack
- **Framework**: Next.js 14 (App Router)
- **AI Core**: Vercel AI SDK (Gemini Pro/Flash)
- **Styling**: Tailwind CSS + Custom Emerald Design Tokens
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Display**: React Markdown + Syntax Highlighting (Prism)
